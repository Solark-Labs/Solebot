# SoleBot — Intelligent Shoe Care

**SoleBot** is a high-end, automated shoe-care protocol designed for luxury footwear and heavy-duty restoration. This landing page serves as the digital interface for the engineering prototype, featuring real-time service simulations and NIR spectroscopy logic.

---

## 🚀 Key Features

* **Intelligent Assessment:** Simulates 3D depth sensing and NIR (Near-Infrared) spectroscopy to identify material types and dirt intensity.
* **The Three-Gate Protocol:**
    1.  **Assessment:** Mud topology mapping and vibration pre-clean.
    2.  **Accountability:** 360° video capture for pre-service condition records.
    3.  **Consent:** Automated service-time estimation based on real-time material ID.
* **Interactive Simulation:** A built-in "SoleBot OS v2.1" emulator that walks users through the intake, laser scanning, and foam-cleaning phases.
* **Cluster Autonomy:** A scaling demo showing how multiple "Bays" can be deployed in high-traffic environments like airports or malls.
